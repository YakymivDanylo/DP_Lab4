# Лабораторна робота 4. Розпізнавання об'єктів CIFAR-10 згортковою нейромережею (Keras)

Згорткова нейронна мережа для розпізнавання 10 класів зображень з набору CIFAR-10
(літак, автомобіль, птах, кіт, олень, собака, жаба, кінь, корабель, вантажівка).
Гіперпараметри підбиралися вручну по одному за раз; результати кожного експерименту
збережено в `results/lab4_results.csv`, графіки навчання в `plots/`.

## Фінальна модель

| Параметр | Значення |
|---|---|
| Згорткові блоки | 3 блоки по 2 шари `Conv2D` 3×3 (`same`), фільтри 64 → 128 → 256 |
| Після кожної згортки | `BatchNormalization` + `ReLU` |
| Після кожного блоку | `MaxPooling2D 2×2` + `Dropout 0.4` |
| Класифікатор | `Flatten` → `Dense(256, relu)` → `Dropout 0.6` → `Dense(10, softmax)` |
| Параметрів | 2 200 394 |
| Оптимізатор / втрата | Adam (lr 0.001) / categorical crossentropy |
| Batch size / епох | 128 / 75 (ваги найкращої епохи за `val_accuracy`, епоха 62) |
| Валідація | 10% навчальних даних (`validation_split=0.1`) |

## Результати

| Модель | Точність на тесті (10 000 зображень) |
|---|---|
| Базова модель з методички | 79,0% |
| Dense-мережа з лаби 2 на CIFAR-10 (для порівняння) | 48,0% |
| **Фінальна модель** | **87,43%** (loss 0,553) |

Точність по класах (тест, `results/per_class_accuracy.csv`): жаба 94,6%, автомобіль 93,5%,
вантажівка 93,1%, корабель 92,0%, літак 90,2%, кінь 87,7%, олень 87,0%, собака 84,8%,
птах 79,5%, кіт 71,9%. Найчастіша помилка: кіт → собака (133 з 1000).
Матриця помилок: `plots/confusion_matrix.png`, приклади розпізнавання: `plots/test_samples.png`
(16 з 20 випадкових тестових зразків).

### Власні зображення (20 фото, по 2 на клас)
Розпізнано **17 з 20 (85%)**, справжній клас у трійці найімовірніших у 19 з 20.
Помилки: `cat2` → кінь, `dog1` → кінь, `frog2` (синя жаба) → птах.

## Підсумок підбору гіперпараметрів

| Параметр | Перевірено | Найкраще |
|---|---|---|
| Кількість згорткових блоків | 1, 2, 3 | 3 |
| Розмір фільтра | 3×3, 5×5, 7×7, змішані | 3×3 |
| Кількість карт ознак | 16-32-64, 32-64-128, 64-128-256 | 64-128-256 |
| Регуляризація | Dropout (4 рівні), BatchNorm, L2 | BatchNorm + Dropout |
| Dense-шари | немає, 128, 256, 512, 1024, 512+256 | один шар 256 |
| Епохи | 20, 25, 30, 50, 75, 100 | 75 |
| Розмір міні-вибірки | 32, 64, 128, 256, 512 | 128 |
| Оптимізатор | SGD, SGD+momentum, RMSprop, Adam | Adam |

Різниця між запусками з однаковою конфігурацією на GPU досягає ≈1 в.п., тому відмінності
менше за 1 в.п. вважалися шумом.

## Як використати збережену модель

Файли `cifar10_model.json` (архітектура) і `cifar10_model.weights.h5` (ваги). Потрібен Keras 3
(у Keras 3 файл ваг повинен закінчуватись на `.weights.h5`).

```python
import urllib.request, numpy as np, keras
from PIL import Image, ImageOps

BASE_URL = 'https://raw.githubusercontent.com/YakymivDanylo/DP_Lab4/production/'
for fname in ['cifar10_model.json', 'cifar10_model.weights.h5']:
    urllib.request.urlretrieve(BASE_URL + fname, fname)

with open('cifar10_model.json') as f:
    model = keras.models.model_from_json(f.read())
model.load_weights('cifar10_model.weights.h5')

CLASSES = ['літак', 'автомобіль', 'птах', 'кіт', 'олень', 'собака', 'жаба', 'кінь', 'корабель', 'вантажівка']

img = Image.open('photo.jpg').convert('RGB')
img = ImageOps.fit(img, (32, 32), method=Image.LANCZOS)      # обрізка по центру + зменшення
x = np.asarray(img, dtype='float32')[None] / 255.0
p = model.predict(x, verbose=0)[0]
print(CLASSES[int(p.argmax())], f'{p.max()*100:.0f}%')
```
